# 🚀 BALI SPACE EXPERIENCE

Real-time audio reactive space visualizer for Windows.

## Vision

BALI SPACE EXPERIENCE is a cinematic 3D universe where the BALI astronaut bear flies through space and reacts to music in real time.

## Core features

- BALI astronaut character
- Deep space environment
- Earth / planets / galaxies
- Asteroids and particles
- Audio reactive animation
- BPM and bass detection
- Camera movement synchronized with music
- Windows fullscreen experience

## Planned technology

- Unreal Engine 5
- Niagara particle systems
- Blueprint logic
- Audio spectrum analysis
- Windows packaged application
