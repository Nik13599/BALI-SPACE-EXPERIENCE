# BALI SPACE EXPERIENCE — Technical Specification

## Engine

Target engine: Unreal Engine 5

## Runtime

Windows application:

`BALI_SPACE.exe`

## Scene

Main scene:

- BALI astronaut bear
- space background
- Earth rotation
- stars
- nebula
- asteroid field

## Audio reactive system

Input:
- Windows audio output
- microphone
- music files

Analysis:
- BPM
- bass energy
- frequency spectrum

## Reactions

Bass hit:
- camera pulse
- suit glow
- particle burst

High frequency:
- star flicker
- dust movement

BPM increase:
- faster flight
- faster planets
- faster particles

## Visual modes

### Lounge
Slow cinematic space flight.

### Club
Dynamic BALI nightclub visual mode.

### Hyperspace
Maximum speed with warp effects.
